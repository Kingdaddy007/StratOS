# Concise Buyer-Facing Decision Aids

Load this reference for a follow-up, service summary, proposal summary, or internal champion aid. Use the smallest format that helps the audience understand the decision. A one-page format is a choice, not a universal maximum.

## Select Modules

| Module | Include when | Guardrail |
| --- | --- | --- |
| Decision and context | Always | Name the decision and use attributed buyer facts. |
| Offered capability | Explaining the offer | State inclusions, limits, dependencies, and version status. |
| Buyer consequence | It helps decision-making | Use financial, operational, experiential, strategic, legal, safety, or uncertainty-reduction consequences only within evidence. |
| Proof | Supported, relevant evidence exists | Preserve source, date, scope, permission, and qualifier. |
| Value scenario | Assumptions are visible | Label it illustrative; show inputs, formula, range, omitted factors, and no-guarantee language. |
| Commercial summary | It is within current authority | State price, scope, conditions, exclusions, and approval status. |
| Next action | A realistic next action is agreed | Make one specific request with owner and timing where known. |

## Layout and Final Meaning

- Make it scannable, legible, and faithful to the evidence.
- Do not use a logo, metric, quote, visual, or headline unless it is attributable, permitted, and correctly scoped.
- Do not hide material limitations in a footnote or use visual hierarchy to overstate an uncertain result.
- Review the rendered asset and its actual distribution channel before release.
