# Cinematic Technique Vocabulary

Load when learning motion vocabulary, translating a reference, or comparing movement families for a named visual / communication job.

These are **techniques, not concepts**. Any technique may be rejected after subject, source, visitor, mobile, accessibility, or cost checks.

## Technique map

| Technique | What it does perceptually | Useful subjects / jobs | Source requirement | Common failure |
| --- | --- | --- | --- | --- |
| **Pan / track** | Moves viewpoint laterally across a field | panorama, collection, spatial survey, sequence | wide source / multiple views / real scene | fake travel through one narrow still |
| **Dolly / push** | Approaches or withdraws from subject | threshold, emphasis, reveal, intimacy | overscan / video / 3D / crop room | cheap scale-up, exposed pixels |
| **Orbit** | Changes view around subject | isolated object, real 3D scene | model / multi-view / rendered media | impossible geometry from a still |
| **Parallax** | Relative movement implies depth | clear foreground / background separation | real or believable depth planes | room-as-stickers |
| **Crop travel** | Changes visible region without claiming new geometry | still photography, detail-to-wide emphasis | high-resolution overscan | crop loses subject / mobile failure |
| **Occlusion reveal** | Near element hides / reveals another | portrait, object, threshold, real foreground | credible silhouette / depth | edge halo, fake layering |
| **Mask reveal** | Content appears through controlled boundary | material, editorial transition, comparison | mask geometry / clean source | arbitrary decorative wipe |
| **Aperture / iris** | Opens / closes field of view | threshold, focus, chapter transition | composition that tolerates crop | theatrical effect with no purpose |
| **Light pass** | Changes attention / material perception through light | stone, metal, textile, space | believable source / compositing | fake glow / poor material response |
| **Focus / blur transition** | Redirects visual attention / depth | subject shift, memory, transition | sufficient resolution / controlled layers | readability / accessibility loss |
| **Scale transition** | Changes hierarchy through size | image-to-detail, object emphasis, typography | layout room / resolution | generic zoom |
| **Object persistence** | One element continues across chapters | recurring subject, guide, comparison | asset continuity / collision plan | gimmick / collision / false continuity |
| **Match movement** | One movement resolves into another state | section / page continuity | aligned start/end states | clever transition with no downstream grammar |
| **Material wipe / pass** | Scene-native matter becomes transition | fabric, shadow, glass, paint, stone, light | relevant asset / mask / media | forced metaphor |
| **Before/after compare** | Exposes difference between states | renovation, styling, process, transformation | paired / aligned evidence | spectacle without explanation |
| **Frame-sequence scrub** | Maps progress to pre-rendered time | controlled camera / object / transformation | rendered frames / preload budget | heavy load / dead scroll |
| **Pre-rendered camera travel** | Presents camera movement without runtime 3D | complex room / impossible runtime scene | video / render | file weight / crop / non-interactive |
| **Layout convergence** | Elements assemble into ordered composition | collection, team, archive | clear start/end layout | motion more interesting than content |
| **Layout dispersal** | Ordered elements separate / expand | exploration, team relationship, gallery | collision / hierarchy planning | chaos / mobile collapse |
| **Typography motion** | Type changes role through position, scale, mask, tracking, etc. | hierarchy, transition, identity | readable states | words become texture only |
| **Hard cut** | No interpolation; immediate state change | contrast, editorial reset, pacing | strong compositions | feels accidental if grammar is unclear |
| **Crossfade** | Softly replaces one state | low-cost transition, reduced motion, image handoff | overlapping states | default used everywhere |
| **Hold / still frame** | Deliberately does not move | proof, inspection, contrast | strong composition | mistaken for unfinished design |

## Camera vs object vs layout

Before selecting a technique, identify what appears to move:

### Camera / viewpoint
Visitor seems to move through / around the scene.

Requires real geometry, multiple views, render, video, or enough crop room to remain honest.

### Object
A subject moves relative to the scene.

Requires believable separation, contact, shadow, scale, and reason.

### Layout
DOM / graphic composition changes while the source media remains intact.

Often safer for real interior photography.

### Time / media
Rendered frames or film progress.

Useful when source already contains the intended movement.

Confusing these categories is a major cause of fake-looking spatial motion.

## Translation from other industries

When borrowing from fashion, automotive, product, film, music video, games, or editorial:

1. Identify the underlying technique.
2. Identify what source conditions made it work.
3. Identify its communication / perceptual job.
4. Compare those conditions with this project.
5. Preserve the principle, not the surface.
6. Prototype the risky translation.

A fashion portrait may support subject cutout + type occlusion.

A full interior may require preserving the room and moving layout / crop instead.

## Technique stacking

Techniques may combine.

Examples:

- dolly + light pass;
- crop travel + typography hold;
- parallax + occlusion;
- frame scrub + fixed annotation.

Combine only when they read as one coherent event.

Avoid building a “demo reel” of unrelated techniques.

## Learning study vs project adoption

A technique recreation may be valuable even when it does not fit the active project.

Store the learned principle as vocabulary.

Do not force every study into client work.
