# Motion Jobs and Grammar

Load when deciding why motion exists, how it should feel, what repeats across the site, or whether multiple animations belong to one coherent system.

## 1. Name the motion job

A motion may perform one or more jobs:

| Job | Visitor effect | Failure risk |
| --- | --- | --- |
| **Reveal** | Exposes content / hierarchy / relationship | Reveal becomes delay |
| **Orient** | Clarifies space, sequence, or state | Motion disorients instead |
| **Transform** | Shows change / comparison | Drama exceeds evidence |
| **Continue** | Carries identity across moments | Persistent element becomes gimmick |
| **Guide attention** | Establishes reading order | Everything competes |
| **Physicality** | Suggests weight, depth, resistance, material | Fake physics / sticker effect |
| **Atmosphere** | Adds low-attention life / environmental character | Wallpaper motion |
| **Rhythm** | Controls cadence and variation | Motion exists only to avoid stillness |
| **Proof support** | Helps compare / inspect / understand evidence | Proof becomes spectacle |
| **Response** | Confirms interaction / agency | Decorative hover noise |
| **State transition** | Makes navigation / filtering / open-close understandable | Transition blocks action |
| **Character** | Expresses brand personality | Generic easing masquerades as personality |

Stillness may perform the job more effectively.

## 2. Separate the five tracks

### Opening / Arrival
First transition into the experience.

Possible states:
- direct resolved hero;
- still first state;
- short reveal;
- title resolution;
- threshold;
- media-to-page handoff.

### Ambient
Low-attention motion that may continue without direct user control.

Examples:
- light drift;
- subtle environmental loop;
- texture / material change;
- slow background movement.

Ambient motion should pause when irrelevant / offscreen when implementation permits.

### Narrative / Scroll
Movement controlled by progress or document position.

Examples:
- crop travel;
- persistent object;
- scrubbed media;
- chapter handoff;
- before/after progression.

### Interaction
Movement caused by agency.

Examples:
- drag;
- project preview;
- selected state;
- hover / focus feedback;
- comparison.

### Navigation / Transition
Movement between structural states.

Examples:
- menu;
- page / route;
- filter;
- project transition;
- modal / panel.

A project may use only one track.

## 3. Define perceptual physics

Use descriptive qualities before numeric values.

### Weight
- light;
- neutral;
- heavy.

### Response
- immediate;
- damped;
- inertial;
- delayed;
- elastic;
- stepped.

### Precision
- exact;
- soft;
- loose;
- organic;
- mechanical.

### Energy
- still;
- restrained;
- calm;
- assertive;
- energetic;
- playful.

### Continuity
- discrete event;
- continuous loop;
- progress-bound;
- persistent across chapters.

These qualities should follow the approved visual / brand character.

There is no universal “luxury easing.”

## 4. Decide what repeats

A repeated rule can become identity.

Possible repeated grammar:

- same camera direction;
- same mask edge;
- same enter / hold / resolve structure;
- same damping character;
- image leads while type holds;
- type leads while image holds;
- same navigation transition;
- repeated pause before proof.

Ask:

- Does repetition make the site feel authored?
- Does it flatten hierarchy?
- Is the same rule appropriate for the content?
- Where should the grammar deliberately break?

**Repeat grammar; vary emphasis.**

## 5. Singular focus is a diagnostic, not a law

Multiple movements may coexist when they form one perceptual relationship.

Example:
- camera moves;
- foreground shifts slightly faster;
- light changes;
- typography stays attached to the frame.

That can still read as one event.

The problem is not “more than one thing moves.”

The problem is unrelated motion competing for attention.

## 6. Stillness as grammar

Stillness may:

- establish seriousness;
- allow inspection;
- create contrast after movement;
- preserve proof;
- make the next movement more meaningful;
- become the dominant identity of the site.

Do not treat still sections as unfinished.

## 7. Reverse behaviour

For scroll-bound / interactive motion, test:

- reverse;
- quick scrub;
- stop mid-state;
- re-entry;
- resize;
- touch;
- deep link.

Some physically irreversible events should not literally reverse.

If reverse looks absurd:
- use a non-reversible triggered event;
- switch to state-based transitions;
- choose a different technique.

## 8. Small motion contract

For a consequential motion:

- **Job**
- **Trigger**
- **Subject**
- **Start / end**
- **Character**
- **What remains still**
- **Continuity rule**
- **Reduced-motion equivalent**
- **Mobile intent**
- **Main risk**

This can be a few lines. Do not create paperwork for every hover.
