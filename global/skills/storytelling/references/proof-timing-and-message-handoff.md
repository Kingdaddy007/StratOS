# Proof Timing and Message Handoff

Load when claims need evidence, case studies feel superficial, words and images duplicate each other, captions are weak, or inquiry appears before enough trust has formed.

## 1. Put proof next to the belief it supports

For each material claim ask:

1. What exactly is being asserted?
2. Is it documented, client-reported, inferred, or proposed?
3. What would a reasonable visitor need to see to believe it?
4. Can available evidence actually support it?
5. Where should the evidence appear?

Qualify or remove claims when proof is absent.

Do not turn generated atmosphere into completed work or mood imagery into evidence of a result.

## 2. Match proof to the value being claimed

| Value | Useful evidence | Common overclaim |
| --- | --- | --- |
| Spatial quality | Complete-room views, plans, circulation, scale, use | One detail proves the room works |
| Design judgment | Constraint, alternatives, decision, result | Beautiful outcome proves sophisticated process |
| Transformation | Before, intervention, after, scope | Every project becomes a dramatic rescue |
| Craft / material intelligence | Detail + context, sourcing, joinery, collaborators | Texture alone proves craftsmanship |
| Collaboration | Roles, process, client / partner account | Group portrait proves collaboration |
| Reliability | Method, timelines, documented commitments, client account | Polished site proves delivery consistency |
| Authorship | Roles, decision ownership, project evidence | Founder portrait proves sole authorship |
| Client trust | Verified testimony, repeat work, referral evidence | Generic praise proves strong outcomes |

The table diagnoses evidence burden. It does not decide the message.

## 3. Divide work between words and images

Let images carry qualities visitors can directly see:

- proportion;
- atmosphere;
- material;
- scale;
- relationship;
- finish;
- spatial continuity.

Let words provide what the image cannot verify:

- project identity;
- client brief;
- constraint;
- decision;
- role;
- method;
- outcome;
- limitation;
- context.

Captions should make visible decisions legible, not merely praise the image.

Typography, crop, layout, motion, and composition remain visual-owner decisions.

## 4. Choose copy behaviour, not final prose

Useful copy modes:

| Mode | Job |
| --- | --- |
| **Orient** | Explain who / what / where |
| **Declare** | State a point of view |
| **Atmosphere** | Add emotional / sensory register |
| **Explain** | Make a decision, process, or relationship legible |
| **Prove** | Supply fact, quote, project detail, or evidence |
| **Guide** | Help interaction / navigation |
| **Invite** | Prepare the next step |
| **Silent** | Let visual evidence carry the chapter |

Do not use one copy mode everywhere.

Every chapter does not need a headline, paragraph, caption, and CTA.

## 5. Strengthen project captions

Useful captions may identify:

- project / location when permitted;
- room / use;
- constraint;
- material;
- decision;
- relationship;
- custom element;
- before / after condition;
- why an unusual move was made.

Weak:

> Warm, timeless living.

Stronger when supported:

> The original circulation crossed the seating zone; new joinery redirects movement along the perimeter.

Never invent a project fact to improve the caption.

## 6. Generic premium language

Words such as:

- luxury;
- bespoke;
- timeless;
- elevated;
- curated;
- refined;
- sophisticated;

are not automatically banned.

Ask whether the word:

- is accurate;
- matters to the audience;
- is supported;
- communicates more than a specific material, decision, process, or outcome would.

Specificity usually beats status signaling.

## 7. Message handoff to visual owners

For each consequential chapter, provide:

- communication job;
- reading priority;
- key claim;
- proof required;
- what the image must show;
- what words must add;
- what must remain legible.

Do not prescribe:

- crop;
- scale;
- whitespace;
- contrast;
- visual intensity;
- typography treatment;
- camera move;
- animation.

Those belong to `spatial-experience-design` and motion owners.

## 8. Inquiry handoff

Given the approved commercial posture, specify what visitors should know before acting and what uncertainty the next step should resolve.

Check:

- relevant work has been shown;
- scope is clear enough;
- proof is sufficient;
- the action is understandable;
- visitors can act without replaying the entire authored sequence.

Leave qualification, exclusivity, pricing, and offer promises to the business owner.

## 9. Smallest useful review

Sample:

- first material claim;
- strongest claim;
- representative project;
- closing action.

Ask whether:

- claim and proof meet;
- words add information;
- images are being asked to prove too much;
- inquiry is understandable;
- selective and return visitors retain enough context.

State what was observed and what remains untested.
