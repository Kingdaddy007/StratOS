# Media Production Mode

## Purpose

Use this mode when supplied assets need approved enhancement, compositing, generation, or source-image-led video before the website can support its selected spatial thesis. Keep media production upstream of broad site implementation and inside an explicit authority and provenance envelope.

## Activation Gate

Require all of the following:

- named asset gap and the website belief or chapter it blocks;
- supplied source files and their provenance;
- confirmation that the user may upload and transform those sources;
- named provider/tool or permission to choose among currently available tools;
- maximum spend or credit budget, generation count, duration, and resolution;
- approved output directory and private-use boundary;
- fallback when the provider, generation, or upload fails.

Verify current provider capabilities and limits at run time from official sources when they affect the plan. Tool availability does not authorize an upload, purchase, or public use.

## Media Route

1. Inventory source quality, orientation, crop flexibility, lighting, geometry, rights uncertainty, and chapter job.
2. Decide whether local crop, tonal correction, cleanup, compositing, a generated variant, or video is actually necessary.
3. Use the host's image-editing capability for bounded image edits when available. Use the Media pack plus `video-generation`; add `prompt-engineering` only for provider-ready prompts.
4. Preserve project truth. Do not fabricate completed work, before/after evidence, client relationships, people, or material performance.
5. For source-image-led video, lock room geometry, camera side, lighting, material placement, text-safe region, movement, duration, end frame, and anti-warp constraints.
6. Generate a bounded candidate set. Record source-to-output lineage, provider/tool, prompt/directive, date, and unresolved rights or realism concerns.
7. Review candidates for project fidelity, spatial consistency, perspective, material truth, human anatomy when present, compression, loops, and mobile crops.
8. Promote only selected outputs into the final asset directory. Keep rejected candidates outside production imports.
9. Re-run the website risk slice with final media before broad production. Return to the thesis or choose a lighter continuity system if the media cannot carry the job credibly.

## Copy-Paste Media Authority Block

Append this to the main one-shot prompt only after filling every bracket:

```text
Media-production authority:
- Provider/tool: [NAME OR APPROVED CHOICE BOUNDARY]
- Source files approved for private upload/transformation: [PATHS]
- Allowed jobs: [CROP / CLEANUP / COMPOSITE / IMAGE VARIANTS / SOURCE-IMAGE-TO-VIDEO]
- Maximum spend or credits: [EXACT LIMIT]
- Maximum candidates: [COUNT]
- Video limit: [COUNT, DURATION, RESOLUTION]
- Final output directory: [PATH]
- Public use: prohibited unless separately approved.
- Stop and preserve the asset directive if provider access, rights, budget, or source fidelity cannot be verified.
```

## Delegation Boundary

Delegate asset inventory, bounded image preparation, or candidate review only with exact source/output ownership. Keep provider approval and final asset selection with the parent. Do not let media workers redesign the website thesis or publish outputs.

## Completion Rule

Media production is complete only when selected outputs have traceable sources, fit the chapter and continuity system, survive desktop/mobile crops, and are imported into a verified risk slice. A beautiful generated file without provenance, narrative job, or responsive use is not complete.
