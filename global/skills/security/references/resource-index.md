# Security Resource Index

Load only the material needed by the active boundary. Pin the referenced standard version in a report. Verify framework, cloud, identity-provider, package-manager, scanner, and legal requirements before implementation.

| Source | Use when | Verified |
| --- | --- | --- |
| [OWASP ASVS 5.0.0](https://owasp.org/www-project-application-security-verification-standard/) | Selecting testable application-security controls or citing a versioned requirement | 2026-08-19 |
| [NIST SSDF](https://csrc.nist.gov/projects/ssdf) | Designing a risk-based secure-development process or assessing a security practice gap | 2026-08-19 |
| [OWASP Authorization Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html) | Designing server-side authorization, ownership, tenant isolation, or negative access tests | 2026-08-19 |
| [OWASP Injection Prevention Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Injection_Prevention_Cheat_Sheet.html) | Tracing untrusted input to interpreters, queries, templates, commands, or renderers | 2026-08-19 |
| [OWASP File Upload Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html) | Designing file validation, storage, access, size/resource limits, or scanning | 2026-08-19 |
| [OWASP Secrets Management Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Secrets_Management_Cheat_Sheet.html) | Selecting a secret supply, rotation, revocation, auditing, or recovery mechanism | 2026-08-19 |
| [OWASP Software Supply Chain Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Software_Supply_Chain_Security_Cheat_Sheet.html) | Assessing dependencies, build actions, provenance, generated imports, or supply-chain controls | 2026-08-19 |
| [OWASP AI Agent Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/AI_Agent_Security_Cheat_Sheet.html) | Designing agent tools, delegation, memory, permissions, auditability, or external action controls | 2026-08-19 |
| [OWASP Prompt Injection](https://genai.owasp.org/llmrisk/llm01-prompt-injection/) | Handling direct or indirect prompt injection and untrusted external content | 2026-08-19 |
| [NIST CVSS metrics](https://nvd.nist.gov/vuln-metrics/cvss) and [FIRST CVSS](https://www.first.org/cvss/specification-document) | Recording technical severity without confusing it with environment-specific risk | 2026-08-19 |
