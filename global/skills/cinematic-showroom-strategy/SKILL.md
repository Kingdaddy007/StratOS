# Cinematic Showroom Strategy — Compatibility Route

question about media source method, proof status, scene continuity,
image-to-video production, crop and text zones, posters, playback states, or
fallbacks, load `media-choreography` and use its current V5 guidance.

`expert-positioning`, `storytelling`, `spatial-experience-design`,
`cinematic-motion`, or `scroll-storyboard` respectively. Do not use this
compatibility name for a new project when the current specialist can be
