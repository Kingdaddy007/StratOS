# Brief and Prompt Composition

## Build the Brief

Capture only information that changes the result:

| Field | Ask or infer |
| --- | --- |
| Goal | What should the viewer understand, feel, or decide? |
| Subject and action | Who or what is on screen, and what materially happens? |
| Setting and time | Where, when, and what environmental condition matters? |
| Visual treatment | Framing, camera intention, light, materials, palette, and realism/stylisation. |
| Temporal plan | One beat for a short test; ordered beats only when the duration supports them. |
| Sound | Silence, ambience, music, dialogue, or supplied audio role. |
| Anchors | Details that must remain recognisable: product, room, face, prop, mark, or final frame. |
| Delivery | Aspect ratio, duration, resolution, use case, and approval criterion. |

Ask only for the missing high-impact facts. Do not force a long interview when the user already has a clear brief and strong references.

## Compile the Prompt

Write a clear scene instruction in this order when useful: subject and action; setting; camera/framing; visual treatment; temporal beat; audio intent; anchors; delivery constraint. Use observable nouns and verbs. Remove hollow praise, conflicting directions, duplicated descriptions, and requirements the provider cannot expose.

If references exist, say what role each serves rather than describing the same information again. Apply a provider's syntax only after the active UI/API confirms it.

## Quality Check

| Weak pattern | Replace with |
| --- | --- |
| Empty praise: “epic”, “beautiful”, “premium” | Observable light, material, framing, motion, or emotion. |
| Contradictory instructions | One chosen priority and an explicit acceptable trade-off. |
| Exhaustive micro-direction | The few details that determine the shot; use a small test for the rest. |
| Fixed prompt length | The active surface's limit, if known; otherwise a concise complete brief. |

Return a production brief first, then a copy-ready provider prompt only when the surface supports the required controls.
