# Reference and Continuity Direction

## Classify Each Asset

Record the asset, rights owner, permitted use, and one intended role:

- **Identity:** subject, product, character, logo, or room features that must remain recognisable.
- **Composition:** opening or closing frame, layout, framing, blocking, or spatial relationship.
- **Look:** material, palette, texture, lighting, or stylisation.
- **Motion:** action, camera rhythm, editing cadence, or transition intent.
- **Sound:** voice, dialogue timing, ambience, music character, or sound-event timing.

Use the minimum references that explain the important constraints. More assets can create conflicts, so name the priority when assets disagree.

## Preserve What Matters

List immutable anchors, acceptable variation, and failure conditions before generation. For a room or product, include geometry/material anchors that must survive. For a character, include the permitted identity source and the review standard. For a multi-shot sequence, approve a stable key shot before creating dependent shots.

Do not promise perfect identity, text rendering, geometry, audio, or long-sequence continuity. Check the actual output against the anchors and regenerate or redesign only after recording the specific drift.

## First and Last Frame Work

Use a start/end composition only when the active provider visibly supports it. State the transition intent and what may change between the frames. Do not invent a provider tag or control from another surface.
