# Production Handoff and Automation

Choose the smallest route that satisfies the actual delivery need: prompt/brief only, user-operated generation, verified provider integration, or local finishing of a file already under authorised control.

For an integration, verify current official API documentation, exact model/API ID, authentication method, inputs, asynchronous lifecycle, quota/cost, retries, error handling, and output/provenance behavior. Keep credentials in the approved secret mechanism; never place them in a prompt, sample, repository file, or screenshot.

For delivery, record source asset, prompt/version, provider/surface/model, settings, result, review findings, licence/consent evidence, output format, and explicit approval status. Do not prescribe a codec, resolution, metadata action, or post-production tool until the project and provider constraints are known.

Stop before provider calls, external uploads, paid generation, destructive metadata changes, publication, or client delivery.
