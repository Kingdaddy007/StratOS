# Seedance Surface Routing

Verification date: 2026-08-19.

Seedance is a ByteDance model family, not one invariant interface. Before loading technical or prompt guidance, record:

1. Creator or API surface: Dreamina, Jimeng, Doubao, CapCut, Pippit, ModelArk playground, or ModelArk API.
2. Exact visible model label or API identifier, including every Lite, Mini, Fast, or Pro suffix.
3. Account access, country/region, credits or API activation, task mode, visible reference controls, export/provenance controls, and applicable terms.

Then load only the matching reference from the `video-generation` resource index. Keep portable creative direction separate from version- and surface-scoped behavior.

Do not transfer a Seedance 2.0 launch limit, a ModelArk role token, a Dreamina UI feature, or a community prompt recipe to another surface. Do not infer price, quality, or access from a suffix. If the exact model/surface is not visible, keep the route unresolved.

Primary sources: [Seedance 2.0 launch](https://seed.bytedance.com/en/blog/official-launch-of-seedance-2-0), [Seedance 2.5 launch](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5), [ModelArk documentation](https://docs.byteplus.com/en/docs/ModelArk/2607689).
