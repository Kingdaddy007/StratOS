# Spatial Subject and Asset Fit

Load when deciding what can be shown, separated, moved, cropped, generated, or simulated in a spatial website.

Use the material to ask better questions, not to force the project into one of the listed lenses.

## 1. Subject lenses

| Subject lens | Visual opportunity | Common failure | Evidence to inspect |
| --- | --- | --- | --- |
| **Complete space** | Atmosphere, volume, sightline, circulation, lived experience | Connected room becomes drifting stickers | Real views, vanishing lines, floor/wall joins, light, crop room |
| **Distinct object** | Silhouette, detail, material, scale, occlusion with type | Generic product theatre overwhelms project context | Shape, light, project role, cutout quality, scale cues |
| **Design decision / transformation** | Before-after logic, material meeting, functional insight, causality | Abstract claim with no visible proof | Before/during/after, detail + wide view, constraint, decision, result |
| **Collection** | Range, comparison, editorial rhythm | Different projects appear to be one fictional space | Project identity, labels, asset variation, chronology |
| **Person / practice** | Authorship, collaboration, craft, personality | Fashion imitation or unsupported authority claim | Real people, roles, relationships, practice evidence |
| **Site / context** | Landscape, heritage, locality, architectural setting | Spectacle replaces work or invents provenance | Real location, rights, relation to actual projects |
| **Other** | Project-specific opportunity | Existing taxonomy distorts the real subject | Define the subject in plain language first |

## 2. Check spatial integrity

Before approving layered depth, camera-like movement, or generated continuity:

1. Locate the implied camera, horizon, and stable vanishing lines.
2. Identify **real occlusions**. A foreground edge can hide type or reveal a space only when it plausibly sits nearer the camera.
3. Check contact relationships. Furniture, shadows, floor, walls, reflections, and joinery should not separate without a reason.
4. Check lighting continuity: direction, exposure, shadow softness, reflections, and colour temperature.
5. Check material scale. Stone, grain, fabric weave, plaster, and joinery must remain credible at hero size and during movement.
6. Check human scale when people or familiar objects provide the size reference.
7. Sample start, middle, end, and reverse states of a scroll illusion. Inspect newly exposed areas and seams, not only the opening frame.
8. Preserve honest project identity when moving between rooms or projects.

## 3. Match movement to source evidence

| Source material | Credible movement | Highest-risk limit |
| --- | --- | --- |
| **One still image** | Crop travel, restrained push, mask reveal, frame/type movement, subtle light treatment | Unseen geometry, stretched pixels, insufficient overscan |
| **Still + true foreground cutout** | Occlusion, restrained relative depth, type behind silhouette | Halos, contact-shadow loss, mismatched perspective/resolution |
| **Several related photographs** | View change, project progression, modest travel / match cut | Camera height, room continuity, lighting, project identity |
| **Film / rendered sequence** | Camera travel, light change, material reveal, scrubbing | Compression, file weight, mobile crop, playback control |
| **Spatial model / 3D scene** | Real orbit, walkthrough, viewpoint change, parallax | Production cost, loading, interaction burden, fallback |
| **Generated exploration** | Mood, speculative scene, visual test, controlled transition | Factual ambiguity, continuity, geometry drift, brand misrepresentation |

**Do not promise visual information the source cannot reveal.**

A long room journey from one still image requires additional source imagery, generated inference clearly treated as such, or actual geometry.

## 4. Ask what the subject permits

Before choosing a technique:

- What must remain visually connected?
- Which elements are truly foreground, midground, and background?
- Is there enough negative / low-detail space for typography?
- Does text-over-image hide evidence the visitor needs?
- Is a crop shift safer than layer separation?
- Is the desired movement really camera movement rather than object movement?
- Would changing light create the feeling more honestly than moving geometry?
- Does the subject need stillness to be understood?
- What is the mobile equivalent?

## 5. Make an asset requirement reviewable

For a decisive asset, capture only what the decision needs:

- **Source + status** — verified client work, client-reported, licensed, proposed generation, exploratory, unknown.
- **Subject + proof job** — what visitors should perceive, learn, or feel.
- **Framing** — viewpoint, focal point, near/far elements, light, material detail.
- **Website fit** — first/later states, desktop/mobile crops, text-safe zones, contrast, resolution, loading order.
- **Motion + fallback** — what may move, what remains fixed, reduced-motion / still state.
- **Rights + continuity** — permission, relation to real work, consistency across scenes.

Route provider prompts, encoding, playback, and detailed production to the appropriate media or engineering owner.

## 6. Correct common visual misreads

| Apparent opportunity | Check first | Likely adjustment |
| --- | --- | --- |
| Rich room could be layered parallax | Are proposed layers truly separable and independently believable? | Keep the room whole; move frame/viewpoint/light or one legitimate occluder |
| Product reference has beautiful type behind subject | Does this project have a clear subject and believable type field? | Use occlusion only where real depth supports it |
| Seamless transition connects two projects | Could visitors read them as one home? | Mark project identity or make the editorial cut intentional |
| AI media can fill a gap | Is it proof or exploration? | Label the role; do not replace factual project evidence |
| Large image seems sharp enough | What happens after overscan, crop, DPR scaling, and compression? | Test actual rendered size before approval |
| Camera move feels cinematic | Does the source actually contain the geometry the move would reveal? | Reduce to crop travel / push, obtain more views, or use real geometry |
| Furniture looks separable from room | Are shadows, reflections, floor contact, and perspective independent? | Treat it as part of the space unless the cutout is genuinely credible |

## 7. Small test rule

When uncertain, test the part most likely to expose falseness:

- edge halos;
- perspective drift;
- newly exposed pixels;
- mobile crop;
- material scale;
- text collision;
- cross-project identity;
- start/end-state continuity.

A beautiful first frame does not prove the illusion.
