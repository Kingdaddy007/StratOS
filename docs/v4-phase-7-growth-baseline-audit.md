## Evidence-led findings

### High — forced route and context creation

The legacy `marketing-copy` workflow required all copywriting, psychology, and editing skills, required contexts that may not exist, and directed agents to run Project Inception and write a context before copy began. This conflicts with the V4 rule that a clear, reversible request can remain direct work and that a workflow cannot upgrade authority.

**Action applied:** replaced the legacy body with a v3 optional Growth coordinator. It selects one owning capability, treats project context as optional evidence, makes planning/review read-only, and retains task-scoped state.

### High — unapproved external outreach language

`prospect-research` used score bands to direct immediate concept creation and outreach sending. Root policy already blocked external effects, but a canonical skill must not present a score as permission to send.

**Action applied:** converted those outcomes into drafts or proposals for human review, added an explicit external-action boundary, and aligned the dossier template/helper action vocabulary. Its local-only helper remains intact and now rejects the old automatic-action label.

### Medium — legacy host/context assumptions

Several skills expect `.agents/product-marketing-context.md` or an older `.claude` location. Existing context can remain useful, but no active Growth route should require an outdated host-specific file or create one merely to begin work.

**Action deferred:** resolve under the research-backed capability update, using portable context discovery and project truth only when it actually exists.

### Medium — capability overlap needs evidence, not compression

Copywriting, editing, psychology, CRO, positioning, sales collateral, and prospect research each have plausible distinct roles. Their current boundaries are not yet consistent enough to merge or shrink them safely. The two focused research briefs decide what stays in entrypoints, what becomes conditional reference material, and what should be removed.
