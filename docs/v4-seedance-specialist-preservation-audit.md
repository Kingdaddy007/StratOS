# V4 Seedance Specialist Preservation Audit

Decision date: 2026-08-19  
Scope: classification and active-catalogue migration. The inherited source package was archived intact; it was not deleted.

## Why This Audit Exists

The prior media profile registered one Seedance parent and 23 child skills as standalone `capability` entries. That was an inventory of past packages, not proof that each one deserved equal default discoverability today.

The evidence synthesis establishes a safer rule: preserve durable filmmaking judgment, but never make a 2.0-specific tag, fixed length, surface, filter claim, API contract, or community result look universal. The decision below is therefore about retrieval and factual scope—not a judgment that creative material is worthless.

## Target Retrieval Model

```text
video-generation
  -> provider/surface/model negotiation
  -> conditional Seedance surface reference
  -> active-surface verification and job route
  -> only the required creative method, safety gate, diagnosis, or integration plan
```

## Classification Ledger

| Archived entry | Useful material to preserve | V4 active treatment | Why it is not a standalone capability |
| --- | --- | --- | --- |
| `seedance` | Job routing, brief, evidence record, approval gates | **Moved into the direct parent** | The single active skill now owns safe surface/model negotiation. |
| `seedance-filter` | Observed-refusal evidence, compliant alternatives | **Moved into diagnosis reference** | Safety/policy diagnosis is a distinct job but does not need a separate user command. |
| `seedance-copyright` | Rights, consent, likeness, publication screening | **Moved into rights reference** | A rights failure can invalidate the project before generation. |
| `seedance-pipeline` | Integration feasibility, secrets, local finishing boundary | **Moved into handoff reference** | Automation and external effects need distinct evidence and approval handling. |
| `seedance-troubleshoot` | Preserve inputs/settings/output and test one causal variable | **Moved into diagnosis reference** | The direct skill hard-coded unverified prompt lengths, tags, and causes. |
| `seedance-audio` | Audio intent, dialogue review, audio/video quality checks | **Moved into audio reference** | The direct skill asserted obsolete formats, limits, modes, and workaround behavior. |
| `seedance-prompt`, `seedance-prompt-short` | Clear subject/action/scene/camera/audio brief; concise drafting | **Merge into parent-routed prompt-composition reference** | The pair duplicates a universal 2.0 formula and fixed word/character targets. |
| `seedance-interview`, `seedance-interview-short` | Fast clarification and a brief-building conversation | **Merge into project/creative-brief method reference** | They duplicate each other and are not provider-specific capabilities. |
| `seedance-camera`, `seedance-motion`, `seedance-lighting`, `seedance-characters`, `seedance-style`, `seedance-vfx` | Camera, motion, light, identity, visual style, and physics language | **Move to selectively loaded creative-method references** | Their visual judgment is useful; their named tags, single-rule claims, and 2.0 behavior must not route every task. |

| `seedance-vocab-zh`, `seedance-vocab-ja`, `seedance-vocab-ko`, `seedance-vocab-es`, `seedance-vocab-ru` | Translation and cinema vocabulary | **Move to indexed language references** | Vocabulary should load only for that language or translation task; current descriptions also contain unsafe “filter-safe” claims. |

## Preservation Requirements Before Any Migration

For each archived row promoted back into active guidance:

1. Copy the useful method into a named parent reference without promoting stale provider facts.
2. Replace provider claims with one of: portable method, dated/surface-scoped fact, historical experiment, or unverified claim.
3. Retain a discoverable user route. For example, a Spanish cinema-term lookup must still find the Spanish vocabulary reference.
4. Add a positive retrieval fixture and a negative fixture proving unrelated video work does not load that material.
5. Validate links, manifest consistency, host adapter output, and no accidental loss of content.

## Migration Result

1. **Brief and prompt composition:** interview/interview-short/prompt/prompt-short/antislop became one selective reference with no fixed 2.0 constraint.
2. **Creative direction:** camera/motion/lighting/characters/style/vfx informed the selective shot, motion, look, and continuity references.
3. **Audio, diagnosis, rights, pipeline:** the useful operational boundaries became four focused references.
4. **Manifest and adapter migration:** the 24 legacy Seedance entries were removed, leaving `video-generation` as the sole active media-generation skill.

## Current Safeguard

`video-generation` and its resource index are the trusted routing entry. The prior Seedance package is preserved in the archive for provenance and later selective curation, but is not loaded or installed. This prevents a six-month-old 2.0 rule from silently becoming the OS's current truth.
